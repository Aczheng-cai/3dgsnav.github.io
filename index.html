Renderable Visual-Spatial Context via
3D Gaussian Splatting for Zero-Shot Object Navigation

1Zhejiang University of Technology.
2Zhejiang University.
*Corresponding author

Abstract

In zero-shot object navigation, access to rich visual-spatial context is critical for reliable target search in unknown environments. Existing methods typically construct abstract scene representations from observations, such as textual descriptions or semantic maps. Consequently, high-level decision-making is constrained by the information preserved in these abstractions, which may omit fine-grained visual details and spatial relationships. In this work, we present 3DGSNav, a novel ZSON framework that leverages 3D Gaussian Splatting to provide VLMs with rich visual-spatial context for navigation reasoning. Through active perception, 3DGSNav selectively acquires complementary observations to incrementally construct a visual-spatial scene representation. Building upon this representation, a trajectory-guided visual evidence generation strategy is employed to optimize virtual viewpoints for generating informative frontier-centric views, while structured visual prompts integrate these views with global spatial context to facilitate VLM reasoning. Moreover, a virtual-view target re-verification strategy exploits the constructed 3D Gaussian scene to obtain complementary visual evidence from alternative viewpoints without additional physical traversal. Extensive evaluations across multiple benchmarks and real-world experiments on a quadruped robot demonstrate robust and competitive performance compared with state-of-the-art approaches.
